# 運動管理アプリ 機能追加設計書(タブ化・時系列表・日記転記ほか)

日付: 2026-08-10
ステータス: 承認済み

## 要望と決定事項(ユーザー確認済み)

1. **タブ化**: 設定欄を常時表示せず、「記録 / 時系列 / 設定」の3タブ構成にする
2. **時系列タブ**: 記録を表形式で時系列参照できるようにする
3. **別の日からコピーの削除**: ボタン・パネル・関連コード・テストを削除
4. **日記転記**: PC側で毎日、記録内容を `01_日記\YYYY-MM-DD.md` に追記する。
   該当日の日記ファイルが無ければ**新規作成して転記**する
5. **PWA名称問題**: manifestに `scope` / `id` を追加。ユーザーには再インストール手順を案内
   (ショートカット追加ではなく「アプリをインストール」でWebAPK化するとアプリ情報が「運動管理」になる)

## アプリ側の設計

### タブ構成

- 下部固定ナビゲーション(カロリー計算アプリの`nav-btn`方式)で3ビューを切替:
  - `view-record`(既定): 現行の記録フォーム(コピーセクションは削除)
  - `view-timeline`: 時系列テーブル
  - `view-settings`: バックアップ設定(`#sync-settings`)+「アプリのURLをコピー」
- ヘッダー(日付ナビ・保存状態)は記録タブでのみ表示

### 時系列タブ

- `js/timeline.js` を新設。タブを開くたびに `getAllRecords` で全件取得し、日付降順で描画
- 列: 日付 / 腹筋 / 背筋 / スクワット / グリップ / 腕立て合計 / 距離km / 時間分 / 天気 / 握力左 / 握力右 / メモ
- 未入力セルは「—」。メモは長文になり得るため先頭12文字+「…」で省略表示
- 表は`overflow-x: auto`のコンテナ内で横スクロール(ページ全体は横スクロールさせない)
- 記録が1件も無いときは「まだ記録がありません」と表示

### manifest

- `"scope": "./"` と `"id": "./"` を追加。他は変更なし

## PC側の日記転記の設計

### 転記スクリプト `tools/transcribe-diary.mjs`(Node)

- 入力: `D:\Obsidian Vault for Claude Code\Git\app-data\exercise-app\backup.json`
- 出力先: `D:\Obsidian Vault for Claude Code\01_日記\<date>.md`
- backup.json内の**全日付**を対象に、日記ファイルへ「運動記録」セクションを書き込む
- **冪等性**: セクションはマーカーコメントで囲む。既存マーカーがあれば中身を置換、
  無ければファイル末尾に追記。日記本文の他の部分には一切触れない

```markdown
<!-- exercise-app:start -->
## 運動記録

- 筋トレ: 腹筋30回 / 背筋20回 / スクワット20回 / グリップ50回 / 腕立て10+12+8=30回
- ジョギング: 06:30出発 ☀️晴れ 3.2km 25分
- 握力: 左42.5kg / 右45.0kg
- メモ: 調子よし
<!-- exercise-app:end -->
```

- 入力済みの項目のみ行を出す(全項目未入力の日はbackup.jsonにレコード自体が無い)
- 日記ファイルが無い日は、マーカーセクションのみのファイルを新規作成する
- ファイルはUTF-8(BOMなし)、改行はファイル既存の形式を保持(新規はCRLF)
- 純ロジック(セクション生成・差し込み)はexport関数に分離しnode:testでテストする

### 実行タイミング

- 既存のタスクスケジューラ **AppDataGitPull** のスクリプト
  `Git\app-sync\tools\app-data-pull.ps1` の`git pull`成功後に
  `node "D:\Obsidian Vault for Claude Code\Git\運動管理アプリ\tools\transcribe-diary.mjs"` を実行し、
  結果をpull-log.txtに追記する。新しいタスクは作らない

## エラー処理

- backup.jsonが無い/壊れている: 転記をスキップしログに記録
- 日記ファイルの読み書き失敗: その日付だけスキップして続行、ログに記録
- 時系列タブのDB読込失敗: 表の代わりにエラーメッセージを表示

## テスト

- timeline: 行の組み立て(降順ソート・null→「—」・メモ省略)を純関数で分離してテスト
- transcribe-diary: セクション文字列の生成、マーカー置換/末尾追記/新規作成の3パターン
- pwaAssets: 既存テストを維持(manifest変更はscope/id追加のみで影響なし)
- コピー機能削除に伴い `copyRecordTo` と関連テストを削除

## やらないこと(YAGNI)

- 時系列のグラフ化・期間フィルタ
- 日記転記のスマホ側実装(PC側のみ)
- 過去の日記ファイル名の表記ゆれ(2026-7-29.md等)への対応(ゼロ埋め名のみ対象)
